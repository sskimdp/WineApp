# Подбор хороших вин

Streamlit-приложение для ДЗ-3: логистическая регрессия предсказывает по лабораторному анализу, хорошее ли вино (оценка не ниже 7).

## Запуск

Python 3.14.4

```bash
cd wine_app
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

Приложение откроется в браузере по адресу http://localhost:8501.

## Файлы

- `app.py` — приложение
- `model.joblib` — пайплайн StandardScaler + LogisticRegression, обученный в ноутбуке
- `config.json` — порог по умолчанию (0.268, максимум F1 на валидации)
- `test.csv` — тестовая выборка для вкладки с метриками
- `requirements.txt` — версии библиотек

## Почему cache_resource для модели и cache_data для таблиц

`st.cache_resource` отдаёт всем вызовам и всем пользователям один и тот же объект. Модель в приложении только читается, поэтому её достаточно загрузить один раз на весь сервер. `st.cache_data` отдаёт каждому вызову копию результата, это подходит для таблиц и массивов: если таблицу случайно изменить, у других пользователей она останется прежней. Если вызвать `joblib.load` без декоратора, модель будет заново читаться с диска при каждом действии пользователя, потому что Streamlit перезапускает скрипт сверху вниз при любом движении слайдера.
